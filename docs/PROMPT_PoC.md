# Claude Code への最初の依頼文（PoC）

以下をそのまま Claude Code に貼り付ける。

---

CLAUDE.md と SPEC.md を読んで、開発ステップ1のPoCを作ってください。

## 作るもの

1. 録音開始／停止ボタンだけのシンプルな画面
2. マイク入力を SpeechAnalyzer + SpeechTranscriber（ja-JP）で文字起こしし、確定した文を画面に時刻付きで表示
3. FluidAudio で話者判別
   - 初回に「自分の声を登録」画面で30秒ほど録音し、声紋を端末内に保存
   - 以降、発話ごとに [自分] / [他人A] / [他人B] … を付けて表示
4. FluidAudio の VAD で無音区間はスキップ
5. 言語モデル（AssetInventory）が未導入なら、ダウンロードを促す表示
